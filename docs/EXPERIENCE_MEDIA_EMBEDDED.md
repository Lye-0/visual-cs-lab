# メディア・組み込みの個別教材：GAP-133〜143

対象は11単元です。単元ごとに対象を選ぶ操作を設計し、共通の自動再生を必須にしません。履歴は現在の実験の取消し用だけで、学習履歴・ノート・外部送信は追加しません。元の授業ノートやそのページ画像も公開しません。

この文書の作成時点では、入口への組込みと専用モデル検査を済ませ、3ブラウザの専用試験を開始する段階です。最終的な成功・失敗、対象SHA、目視できた範囲は別の検証記録に残します。「組込み済み」は、全314ページの教え方や実機での検証の完成を意味しません。

## 表現と範囲

| 単元 | 直接操作する対象と読む対応 | 限定する範囲・別章 |
|---|---|---|
| GAP-133 Fourier | 周波数の組を外す・戻す・位相を0にする。標本を選び、全係数の寄与と復元値を同時に読む。 | 固定16点。kとN−kの共役をまとめ、0/Nyquistは単独。窓の比較、FFTと直接DFTの照合、連続周期関数の級数は別章。 |
| GAP-134 フィルター | 入力一つを書き換え、出力を選んで遅れた入力・過去の出力・倍率・積を対応表示。 | 8点の有限例。一般の係数・周波数応答・極の計算は別章。有限の表示が収まることを安定性の証明にしない。 |
| GAP-135 標本化 | 1Hz/7Hzの波を、同じ記録時刻で比較。時刻の間隔と値の量子化段階を別に選ぶ。 | 端点を含む一様量子化。保持・補間・有限sinc和・ディザは別章。滑らかな表示を情報の完全復元と扱わない。 |
| GAP-136 画像 | 元画素と結果を並べ、出力の場所を押すと使った近傍を強調。元画素を編集し、度数の元の番号も読む。 | 直接操作は8×8の濃淡。画像外は0、二値化・膨張・収縮は同じ元画像から一回ずつ。16×16 RGB、HSV、CDF、逆写像は別章。 |
| GAP-137 描画 | 頂点の物体/view/clip/NDCを並べ、画素を選び、各面の被覆と深度判定を読む。 | 固定6頂点の2三角形。画面y下向き、NDC zは−1〜1。nearは交点追加で切取り。立方体全体と描画順の比較は別章。初期画素は両面が実際に重なる27番。 |
| GAP-138 照明 | 球の同じ点を選んで光を変更し、法線・内積・反射・UV・色を同時表示。 | 正面視線、経験的Phong型、0方向を拒否。物理的な光輸送全体ではない。複数点の画素標本化は別章。 |
| GAP-139 曲線・圧縮 | Bezierの制御点をクリック/矢印/数値で動かし、内分の全段を残す。DCTでは係数を選んで外し、基底と一画素への寄与を読む。 | 三次Bezier、4×4直交DCT。DCTは128を引いて変換し、元画素は保持。2D角度、8×8量子化、DPCM、動画ブロック対応は別章。完全なJPEG/動画符号器ではない。 |
| GAP-140 ピン・PWM | 方向/出力/外部入力のbitを直接押し、PINの参照元を読む。カウンタを一回ずつ進めHighの期間を確かめる。 | 仮想8bitと固定TOP9。PWMは平均と同じ電圧を常時出すものと説明しない。UART/I²C/SPIは別章。特定マイコンの電気条件・更新バッファは省略。 |
| GAP-141 センサー | 既知の0℃/50℃の基準を自分で取得してから校正。電圧・ADC・読み戻す温度を並べる。 | 架空の線形センサー。測る温度の変更では基準を保持、測定器の特性変更では無効化。雑音と平均、周期内の電流、CoAPは別の観点。 |
| GAP-142 制御 | 同じ目標を二つの対象へ与え、積分制限の有無を比較。目標変更で位置・速度・積分を消さず、P/I/D・要求・実際の力を読む。 | dt0.05のRK4、最大10秒、質量1・抵抗0.5・ばね0.25、固定ゲインと上限。旧詳細実験とは係数を区別。遅れ・対象の式・極は別章。 |
| GAP-143 締切 | readyの仕事から次に実行する仕事を本人が選ぶ。誤選択では時計を進めず、理由を表示。 | 固定A(C2,T5)・B(C4,T7)、20tick、RM/EDF。期限ちょうどの完了は成功。優先度逆転・継承は別の固定例で比較。有限実験で全期間を保証しない。 |

## 教え方の仕上げで区別すること

値と図の対応、途中式の理由、入力前後の関係を主題にします。単に処理済み画像を次々に表示することを全単元の中心にはしません。なお、全314ページの個別計画との最終照合は残っています。直接操作を追加した範囲と、既存モデルの図・表を比較して読む範囲を上表で分けました。

生成したスクリーンショットの目視レビュー、スクリーンリーダー、スマートフォン実機、Safari実機の確認は自動試験と別に記録します。自動検査が通ったという理由だけで読者にとって分かりやすいと断言しません。
