# 検証結果 — Visual CS Lab 2.0.0

## 対象と結果

再生成した単体 `index.html` と、その生成元 `src/` を検証しました。元の144単元、20分野、ネットワーク20テーマ、セキュリティ24テーマ、総合演習8系列、おすすめの順番8本を維持しています。

| 検証 | 結果 |
|---|---|
| Node.js 自動テスト | **1,133件成功、0件失敗**（サブテストを含む） |
| ブラウザの全体回帰確認 | **3,330項目成功** |
| 非同期処理・実際の図操作・比較図等の追加確認 | **46項目成功** |
| 開いた単元ページ | 全144ページ、デスクトップ幅・モバイル幅で確認 |
| ブラウザ文書で実際にモデルを計算した単元 | 139本。初期条件と各単元のB条件を確認 |
| 暗号APIを使えない環境の案内を確認した単元 | 5本。実計算はNode.jsで別途検証 |
| ブラウザ全体回帰テスト中の未処理例外・通信要求 | いずれも0件 |
| 単体HTMLのビルド・単元一覧の再生成 | 成功 |

件数は独立した算法の数や、実機で操作した人数ではありません。モデルの境界値、各ページの表示項目、ステップ同期などを個別のアサーションとして数えています。全入力の組み合わせを総当たりした検証ではありません。

## 1. 学習履歴・ノート・保存の削除

学習履歴、完了状態、お気に入り、ノート、前回の入力条件、比較、回答を永続保存するコードとUIがないことを確認しました。旧ノート画面、JSON入出力、Markdown書き出し、履歴を使うダッシュボードも対象です。

起動時は旧版の `visual-cs-lab:v1` だけを削除し、旧データの読み込み、新規書き込み、他のキーの削除、ストレージ全消去を行わないことをテストしました。ストレージAPIがない場合、アクセスが拒否される場合でも起動します。

通常のブラウザ回帰テストはストレージ代替を必要としません。旧キー削除のテストだけは明示的なテスト用オブジェクトを使用し、操作記録と無関係のデータが残ることを確認しています。これは実際の別オリジンや旧file URLの保存領域まで削除できるという証明ではありません。

画面移動・アプリ再読み込みで、入力、再生位置、比較、回答が初期化されることも確認しました。ブラウザ自身のURL閲覧履歴はサイトの学習記録とは別です。

## 2. 探す・理解する・条件を変える

ホームの即時検索、検索ダイアログ、複数語、全角英数字、かなの正規化、結果なしからの復帰、絞り込み、矛盾するフィルターの解除、検索時の入力フォーカスを確認しました。

全144単元の単元名、短い説明、操作案内、観察点を点検し、新しいデータ定義を追加しました。各単元には実行可能なB条件を用意しています。Node.jsでは全144本で、Bの条件が有効であること、実計算と描画生成が成功すること、初期条件とは観察可能な結果の違いがあることを確認しました。差が最終指標ではなく途中の手順に表れる単元もあります。

ブラウザでは139本の初期条件とB条件を実計算し、比較、モデルの説明、確認問題、モバイル表示を確認しました。確認問題の回答は保存しません。

A/B比較では、条件表・最終指標と、読み取り専用の図・手順を表示します。二つの図の手順を独立して変更でき、メインの再生位置が変わらないこと、同一画面内のSVG/DOMのIDが衝突しないこと、ネットワーク図の色と文字が正しく適用されることを確認しました。

## 3. 再生・シーク・入力

共通プレイヤーは独立したテスト対象にしました。0・1・複数状態、再生、停止、再開、終了後の再実行、境界のシーク、速度変更、破棄後のタイマー、再入可能な更新通知などを検証しています。全144単元の結果の長さについても確認しました。

ブラウザの標準条件では、手順を再生できる132単元と、入力即時型7単元を実際に表示しました。全139単元の初期条件が持つ792フレームを画面に反映し、現在の状態と手順の同期を確認しました。入力即時型では不要な再生UIを隠します。

代表実験では実際のマウスクリック・ドラッグ、rangeのHome/End/矢印キー、Space、タッチ入力のエミュレーションを使いました。44pxの進行バー操作領域、再生中の停止、末尾からの再実行、条件変更後に先頭へ戻ること、検索表示時・画面移動時の停止も確認しました。

数値欄を空にする、同じ数値を貼り直す、範囲外の数値を確定する、再生中に条件を変える、無効なCPU命令を入力して初期状態に戻す、といった操作もテストしています。未反映入力・計算中は古い結果を区別し、エラー時には古い結果を消して復帰手段を表示します。

追加テストでは、**実際のモデル計算の前後に遅延だけを挿入**して、古い非同期結果が新しい入力や別単元を上書きしないことを確かめました。計算結果そのものを偽の値に置き換えたテストではありません。この遅延コードは配布HTMLに含まれません。

## 4. 図の操作・レスポンシブ表示

仮想ネットワークでは、機器の実際のドラッグ、機器追加、スイッチとの接続、リンク切断をブラウザのポインター操作で確認しました。ドラッグ直後の別機器へのクリックが誤って無視される問題も修正しています。

全144単元を1440px幅・390px幅で開き、ページ全体の意図しない横はみ出しがないことを確認しました。トップ・一覧等と8つの学習順ページは320px幅でも確認し、代表5単元では320px・768px・1920px幅も追加しました。大きな図・コード・表の内部スクロールは意図した動作です。

ホーム、TCP、CORS、Git、論理ゲート、ネットワーク構築のデスクトップ／モバイル画面、およびA/B比較のスクリーンショットを収録しています。31種類の図についてもブラウザの描画を取得して目視確認しました。残る暗号ダイジェスト表示系は、下記のブラウザ制約があり、Node.jsでの可視化HTML生成を検証しています。

## 5. 計算モデルとローカルサーバー

元の算法・モデルに対する期待値、不変条件、境界値のテストを維持しています。対象は数値表現、符号化、数学、ソート、経路、CPU、キャッシュ、メモリ、GC、ネットワーク、権限、Webの安全境界、Git等です。すべての授業内容の正確性を第三者が認証したものではありません。

AES-GCM、SHA-256、HMAC、ECDSA、PBKDF2はNode.jsのWeb Cryptoで実計算しています。

ローカルHTTPサーバーは、Node.jsから実際にループバックへ接続し、HTML・ソース、HEAD、MIME、404、不正URL、経路外アクセス拒否、書き込みメソッド拒否、PORT設定をテストしました。

## 6. 制作環境の制約と未検証部分

**通常のHTTP URL・file URLをChromiumで開くテストは、この制作環境では完了できていません。** 管理されたナビゲーション制限があるためです。ポリシーを変更せず、オフラインのChromiumに `page.set_content` で実際の単体HTMLを読み込み、UIと計算を検証しました。HTTPサーバーの応答確認は前述のNode.jsテストです。

このメモリ内文書は不透明なオリジンで、Web Cryptoの `crypto.subtle` を利用できません。以下の5単元は「利用できない環境」という案内と復帰情報をブラウザで確認し、結果を偽って表示していません。実計算と可視化生成はNode.jsで検証しました。

| ID | 内容 |
|---|---|
| s03-aes | AES-GCMの暗号化・復号・認証 |
| s04-hash | SHA-256と変更前後の比較 |
| s04-hmac | HMACによる検証 |
| s04-signature | ECDSA署名・検証 |
| s07-password | PBKDF2 |

実物のiPhone／Android、Safari、Firefox、支援技術全般、公開先ごとのCSP、実オリジンでの旧保存データ削除は未検証です。タッチ確認はChromiumのエミュレーションであり、物理端末での確認ではありません。

この報告は全規格への適合証明、教材内容に誤りがないこと、どの端末でも不具合がないことを保証するものではありません。モデルの前提と省略は `MODEL_SCOPE.md` と各単元の「モデルと根拠」を参照してください。

## 環境・再実行

Node.js 22.16.0、Chromium 144.0.7559.96、Linux Debian 13、Python Playwrightを使用しました。主なビューポートは1440×1050と390×844です。制作日と配布HTMLのハッシュは `verification/release.json` に記録しています。

```powershell
npm run check

# Python PlaywrightとChromiumを別途用意した場合のみ
python tests/browser_in_memory.py
python tests/browser_behaviors.py
```

基本のNode.js検証とサイトの利用には、npm依存パッケージを追加する必要はありません。ブラウザテストは `CHROMIUM_PATH` で実行ファイルを指定できます。出力先は `QA_OUTPUT`、既定は `test-results/` です。二つのブラウザテストは異なるレポート名を使います。
