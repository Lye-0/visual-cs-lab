# 再現範囲と、再現しないこと

## 全体

この版は**144本の実行可能な教材を持つサイト**です。計画にあった20分野、N01〜N20、S01〜S24、総合演習8系列の入口を残しています。各分野に代表実験を実装したものであり、すべての授業内容・プロトコル仕様・発展算法を完全収録した百科事典ではありません。

### 3種類の計算を区別する

1. **実際の算法・データ処理**：ソート、B+木、Huffman、CRC、Hamming、行列、微分の差分、数値積分、Dijkstra、ビット変換、kNN、画像畳み込み等。
2. **指定した条件のシミュレーション**：教材ISA、キャッシュ、ページ置換、Mark & Sweep、TLB、FIFO・優先キュー、仮想Git等。
3. **手順・条件に絞ったモデル**：TLS、認証方針、Webの脆弱性と対策、クラウド、IoTの更新、インシデントの考察、AIの信頼境界、総合設計演習等。

どの種類も、入力を変更すると計算・判定・状態が変わります。ただし、種類3を実機や実プロトコルの動作確認と同一には扱いません。

## 重要な制約

| 領域 | この版で再現すること | 省略・注意 |
|---|---|---|
| TCPの損失 | 固定1000Bセグメント、有限ウィンドウ、1回の指定損失、累積受信位置、タイムアウト回復 | 接続済み。高速再送・SACK・ACK圧縮・実機のタイマー更新はなし。時間はラウンド×RTT＋固定待ち |
| 輻輳制御 | Reno系の増減を固定ラウンドで説明 | Fast Recovery、CUBIC、BBR、実測速度ではない |
| HTTPの比較 | 接続済み、固定RTT、十分な帯域、HTTP/1.1の単一接続とHTTP/2・3の比較 | 一般的なブラウザ速度ランキングではない。QUICの全機構を含まない |
| IPv4・VLSM | ビット・マスク・ネットワーク境界・固定/24内の割当 | VLSMは従来型LANを仮定し、/31・/32は扱わない。通常のサブネット実験では別途表示 |
| IPv6 | 圧縮表記の展開、固定/64のSLAACとDADの条件 | IIDの生成方式、全寿命管理、更新、再送はなし |
| 経路 | グラフ上の最短経路、最長一致、LOCAL_PREF優先の抜粋、リンク情報の配布 | OSPF/BGPの全実装や実際の収束時間ではない |
| ネットワーク構成エディタ | 機器追加・移動・接続・切断、辺のコスト、到達性と経路 | IP、ARP、DNS、TCPが自動的に統合される万能エミュレータではない |
| 無線・QoS | 送信機会の競合、有限バッファ、FIFO/厳密優先 | 電波伝搬の物理シミュレーション、802.11の全仕様、実音声の品質測定ではない |
| TLS | 名前・期間・信頼・秘密鍵証明と基本的な接続フロー | 証明書の実パース/チェーン検証や通信は行わない。PSK/0-RTT等は省略 |
| Web Crypto | AES-GCM、SHA-256、HMAC-SHA-256、ECDSA-P256、PBKDF2の実計算 | 公開してよい教材データだけを使用。設定値を実サービスへ流用しない |
| 小さいRSA/DH | 公開値、秘密指数、合同式を実計算 | 小さい固定素数。実用暗号ではない。RSAの安全なパディング等はなし |
| 秘密分散 | 有限体上の2-of-5補間計算 | 係数を固定公開しているため、教材自体には秘密性がない |
| ZK・耐量子 | 洞窟の類推、独立試行の確率、入力サイズから移行時の伝送量を計算 | 実用ZK証明・ML-KEM/ML-DSA等は未実装 |
| セッション・OAuth | 期限・失効・署名を条件として評価、認可/認証フローの違い | OAuth/OIDCサーバー、実トークン発行、全攻撃条件は対象外 |
| Webの脆弱性 | 固定の入力経路・出力文脈・権限・対策条件を比較 | SQLエンジンや実サイトに攻撃を実行しない。万能スキャナーではない |
| 検知 | 正解ラベルを持つ合成100イベント、閾値、混同行列 | 点数が現実の攻撃確率という意味ではない。実ログのAI解析ではない |
| 調査 | 架空ログ、時計のずれ、観測事実と仮説 | 人物・流出先等を証拠なく特定しない |
| CPU | MOV/ADD等の固定ISA、4レジスタ、上限付き実行 | x86/ARM/RISC-Vの実バイナリは実行しない |
| パイプライン | 固定5段、指定した1つの依存条件 | 複数発行・実キャッシュ・投機実行はなし |
| TLB・GC | 4仮想ページ、固定PFN、権限、LRU。固定グラフのMark & Sweep | 実OSのページ表や、ブラウザのGCを操作しない |
| スケジューラ | 到着時刻0、固定CPU量、FCFS/SJF/RR | I/O、任意到着、切替コストはなし |
| セマフォ | 原子的なtry-waitで空き/要素数を管理 | ブロックしたスレッドの自動再開はモデル化しない |
| Git | 別々のwork/index/tree、仮想ref、ファイル単位の3-way merge等 | 実OIDではない。ファイル内容の行単位マージ、任意のrebase、全porcelainコマンドは未対応 |
| リモートGit | 仮想remote/trackingの違いとfetch/push/pull | 仮想環境はオブジェクト空間を共有。ネットワーク転送、pack、認証は省略 |
| 学習確認 | モデルに対応した3択問題と試行案内 | 修了認定・能力測定・試験の代替ではない |

## 学修要覧から分かること・分からないこと

提供資料から使用したのは、科目名と分野構成です。このサイトの細かいプロトコル選定、実験数、問い、数値、制作順、モデルは独自に設計しています。

したがって「N08にBGPがある」ことを、「その授業でBGPが必ず出る」という意味で受け取らないでください。履修要件や公式の授業内容は大学の資料で確認する必要があります。

## 指標の読み方

実験画面の右側は、その条件を最後まで実行した最終指標です。「今起きたこと」は選んだステップです。再生途中の説明と最終結果を同じ時点の値として混ぜないように表示しています。

時間・回数・確率等は各モデルの仮定で計算した値です。実測値、セキュリティ認証、数学的な一般の証明とは区別してください。

## 個別の前提

全実験の`scope`と`limits`は [EXPERIMENTS.md](EXPERIMENTS.md) と画面内「モデルと根拠」に掲載しています。ソースコードに加え、代表値・境界値・関係が保たれることを確かめる自動テストを同梱しています。
