## 仕組みの確認に使う一次資料

- POSIX.1-2024 [read](https://pubs.opengroup.org/onlinepubs/9799919799/functions/read.html): パイプの待機・EOF・要求より短い読取り。
- POSIX.1-2024 [pthread_cond_clockwait](https://pubs.opengroup.org/onlinepubs/9799919799/functions/pthread_cond_clockwait.html): mutexを解放して条件待ちし、戻る際の再獲得。
- PostgreSQL 18 [Transaction Isolation](https://www.postgresql.org/docs/18/transaction-iso.html): 文ごととトランザクションのスナップショット、最初のデータ操作、再試行の前提。ただし本教材のcommit時競合検査は簡略化したもの。
- AWS Builders' Library [Making retries safe with idempotent APIs](https://aws.amazon.com/builders-library/making-retries-safe-with-idempotent-APIs/): 要求ID・同じIDの別意図・記録と更新の原子性。
- Ongaro / Ousterhout [Raft](https://raft.github.io/raft.pdf): 選挙・log・確定条件の参考。実装範囲は各章で限定。

資料の本文・図を転載せず、独自の小例と説明・操作モデルを作っています。
