# 開発・HCI・研究・Webの個別教材：GAP-144〜155

この範囲は12単元・28章です。要求・オブジェクト・テスト・版・実験の割当・根拠・要求処理を本人が操作する11種類の画面と、ブラウザの本物の要素を使う6種類の小さなページを追加しました。

全314単元の新しい画面への登録と、全ページの個別計画・教え方の最終確認は別です。登録数を埋めるための仮の定義は追加せず、それぞれの問い・文章・比較例・活動を明示しています。これまでの範囲の計画上の残件を、この登録完了によって解消した扱いにはしません。mainへのマージも別の作業です。

## 実際のDOMを使う範囲

`feedback-specimen`、`target-specimen`、`accessibility-specimen`、`layout-specimen`、`event-specimen`、`form-specimen` は `curriculum-demo-visuals.js` の本物のDOMと処理を再利用します。実験を先に置き、後からその実験だけの条件を変更して比べます。条件変更ではその枠を初期化します。

構成し直した後や別ページへ移動した後に、古い非同期削除や遅れた初期化が新しい枠へ反映されないように、世代と接続状態を検査します。操作の安全性と教材上の反例を区別し、フォーカスを外す等の比較は指定した小さな枠のみに限定します。

## 同時に見直したメディア教材

グラフの横軸へ実際の時刻を表示できるようにしました。1秒の波を0〜160秒と誤読させず、制御では最初の積分後が0.05秒であることを軸にも対応させます。

GAP-141の測定・平均と省電力の説明を別章へ分割しました。以前の `noise-power` の章IDはリンク互換性のため維持し、`power` では同じ10秒周期のsleepの有無を比較します。メディア・組み込みの章数は32から33へ増えました。

## 公開・検証の境界

操作記録は現在の実験のためだけです。学習履歴、ノート、外部通信、API鍵、CDN、任意JavaScriptの実行は追加していません。共有されたPDFやその画像をリポジトリへ追加していません。

ローカルの独立したNode.js検査では全314の登録を確認しました。GitHub上でも14ファイルのハッシュを、ローカルで検査した同じバイト列と照合したうえで入口をコミットしました。入口生成に使う一回限りの作業ワークフローは自身を削除します。恒久テストは読み取り専用です。

最終的なブラウザ試験の成功・失敗と対象SHAは `docs/verification/` に記録します。画面の全機能、全教材の理解しやすさ、実機・補助技術での操作性を、Nodeの成功件数や登録数だけで保証しません。
