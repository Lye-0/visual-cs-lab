# 2.0.0 — 探してすぐに実験するサイトへ

## 削除

学習履歴、学習済み・理解済みの進捗、ノート、お気に入り、最終訪問単元、入力条件の再訪時復元、比較の永続保存、JSON入出力、ノートのMarkdown出力、学習履歴を集計するダッシュボードを削除しました。

旧版の自サイト専用ローカル保存キーは、アクセスできる範囲で起動時に削除します。他のアプリの保存データには触れません。

## 単元を探す入口

検索をホームの中心にし、入力中に単元名・短い説明付きの結果を表示します。専門分野、専門テーマ、20分野、授業の科目名、おすすめの順番からも直接実験を開けます。

検索では複数語・全角英数・ひらがな／カタカナを正規化します。検索途中に入力フォーカスを失わず、矛盾する分野フィルターも解除するよう修正しました。

## 全144単元の操作案内

元の全単元を維持し、それぞれに識別しやすい単元名、簡潔な目的、具体的な観察点、実際に実行するA/B比較例を追加しました。

操作案内は「Aで試す → Bの条件で試す → この違いを見る」です。単に説明文を変えるのではなく、Bボタンが入力条件と計算結果を変更します。初期条件との比較は画面を開いている間だけ利用できます。

最終指標が同じでも内部の状態が違う場合に備え、A/Bの図と説明を並べ、それぞれの手順を選べる比較も追加しました。比較図は読み取り専用で、元のネットワーク構成などを誤って変更しません。

単元名と「どんな実験をするか」という見出しを分け、現在のステップと最終結果も区別します。教材の前提・省略・参考資料はそのまま確認できます。

## 再生と進行バー

DOMから独立した共通プレイヤーに置き換えました。

- 再生、一時停止、途中からの再開、末尾での停止、末尾からの再実行。
- 進行バーのタップ、ドラッグ、矢印キー、Home、Endとモデル内の位置の同期。
- 入力rangeの操作領域を44pxに拡大し、細い線だけに触れなければならない状態を解消。
- 再生中でもrange入力そのものを置き換えず、図の高さによってバーが移動しない構成。
- 速度変更時にタイマーを二重に登録しない。再生速度はモデル内の時間・最終結果を変えない。
- 条件変更、画面移動、検索／用語ダイアログの表示、非表示タブで再生を停止。
- 条件変更後は末尾に飛ばず、新しい条件の先頭から観察。
- 古い非同期結果やタイマーが、別の入力・別の単元の表示を上書きしない。

7本の入力即時型実験には再生操作を表示しません。その他も結果が1状態の場合は動的に直接操作の案内へ切り替えます。

## 入力とエラー

数値の直接入力とスライダーを同期し、空欄の編集中は古い結果を未反映として区別します。文字列は入力後、コードは明示的な反映操作で実行します。

未反映・計算中の比較を禁止し、エラー時は古い図や指標を消します。初期条件に戻して再試行でき、モデルの説明はエラー時も読めます。

## 表示

シックなダークテーマを維持し、説明の文字サイズ・間隔と操作領域を調整しました。スマートフォンでは図と再生を先に置き、入力欄への移動ボタンを設けました。大きな図や表は内部スクロールで読めます。小さいGit履歴の過大な空白を減らし、履歴と作業ファイル・ステージの関係を見やすくしました。別の単元に移った際は、前の単元の通知も消します。

## 変えていないこと

元の20分野・144単元、ネットワークとセキュリティの重点構成、既存の計算モデル・前提・省略、仮想Git、外部接続を必要としない単体HTML配布を維持しています。実機エミュレーターや安全認証ツールに拡張したという意味ではありません。

検証範囲は `TEST_REPORT.md`、操作はルートの `README.md` を参照してください。
