# v3: 解説・図・操作を結び付ける改修

## 維持する条件

元の20分野・144単元を削らず、15単元を追加する。ネットワークとセキュリティを重点化する。履歴、ノート、進捗、お気に入り、入力の永続保存は復活させない。提供された授業ノートそのものは公開しない。

## 教材画面の変更

従来の入力欄を中心にしたワークベンチとは別に、各単元の入口を解説型画面へ変更した。固有の「必要になる場面」「意味」「初期例」「混同しやすい点」を教材データとして用意し、背景・例・条件変更・確認の4区切りで読める。

図の現在段階、値、理由、操作位置を同じ状態から描画する。選択できる対象がある図では、表・式・ビット・行列の対応を強調する。初期例の説明と、利用者が変更した現在の条件を区別する。詳細ワークベンチへも直接切り替えられる。

新しい教材も限定モデルであり、授業ノートにあるすべての説明・証明・操作を完全再現したわけではない。たとえば仮想アドレスの導入は対応先をたどる固定配置で、任意のOSを実行するものではない。NFAは固定した例で、任意のNFAを編集・変換するエディターではない。

## 操作の修正

- 複数の入力エラーを項目ごとに保持し、別の項目を変えただけでは計算を再開しない。
- 未反映のコードを説明タブの切替や別項目の編集で勝手に実行しない。
- 計算中・入力エラーの間は古い結果を消し、古い非同期計算が新しい条件を上書きしない。
- 画面移動時に予約した再計算とプレイヤーを破棄する。
- 新しく表示した手順ボタンも現在の再生位置に合わせて無効化する。
- 直接入力の単元では、不要な再生・次段階ボタンを出さない。
- 図中で行列を開いた状態を保ちつつ、選択対象と説明を更新する。
- 初期化時に回答とフィードバックの表示をともに消す。
- 図の手動強調は次の段階へ持ち越さず、進んだ段階の強調に戻す。
- 説明・入力条件・図を往復するボタンを追加する。

## 検証の区別

`tests/pedagogy.test.mjs` は、単元の欠落や例の構造、比較条件を検査する。分かりやすさそのものを自動採点するものではない。「授業ノートへの言及」を保存機能の残存と誤判定しないように修正した。

`tests/notes-models.test.mjs` は、エントロピーの既知値、行列の整合性、単一ビット誤り、NFAの全短入力、NAND、レジスタ、アドレス分離などを独立の期待値で検査する。

`tests/reader-browser.mjs` は全単元の実HTTP試験、`tests/reader-regressions.mjs` は入力・フォーカス・巻戻し・古い計算の競合などの試験を担当する。数値とページ表示の試験、目視のデザイン評価、授業ノートとの内容照合、初心者の理解度確認は、それぞれ別の確認である。

最新の実行結果は `docs/verification/TEST_REPORT-v3.md` を参照する。旧v2のレポートや画像を、新しい教材の検証済み証拠として再利用しない。
