# ε–δで理解する極限と連続性

追加単元 `c03-epsilon-delta`。数学・理論／解析に配置し、GAP-004と相互に関連付ける。既存のGAP番号は維持する。

## 教材の順序

1. 一次関数で、入力の距離δと出力の誤差εを同じグラフに表示。一点の成功と範囲全体の保証を分ける。
2. ε→δ→全てのxという量化の順序。εだけを変更して条件が崩れることを観察する。
3. x²の因数分解とδ=min(1,ε/3)の十分性を、不等式の各行で説明する。
4. 穴の位置の値を変えて、極限と連続性の違いを見る。
5. 段差に対し、固定ε₀=0.25と任意のδの反例±δ/2を対応させる。

## 判定と表示の境界

有限サンプリングは描画専用。入力小数はBigIntの有理数に直し、厳密な大小関係で判定する。一次関数の誤差上限は2δ、x²では2δ+δ²、穴ではδ。開区間では上限を取らないので上限≤εで成立する。段差は最大値を実際に取るため、max(|L|,|1−L|)<εが必要。

不成立時は対象範囲内の反例を構成し、正確な分数も表示する。UIのε・δの範囲は有限であり、全てのεの証明は本文の一般式が担う。「今回の条件の成立」を極限の証明と呼ばない。

入力・SVG外枠を保持して更新する。軸は各関数で固定し、数値入力、グラフのクリック、左右キーで点を選べる。カスタム数値入力・プルダウンとラベルの非作動規則は既存実装を利用する。
