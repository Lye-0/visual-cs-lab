# 分野とテーマから探す

## 分類の原則

教材本体314単元のID、計算モデル、旧20分野の識別子は維持します。公開用の入口は `src/taxonomy.js` に集約し、8大分類から61テーマ、単元へ進めます。各単元には1つの主分類があり、合計件数を重複させません。関連分類は検索用の補助語です。大学の公式な科目構成・履修範囲を保証する分類ではありません。

| 大分類 | 主なテーマ |
|---|---|
| 数学・理論 | 線形代数、微積分、数値解析、確率、統計、離散数学、計算理論、情報量、符号、圧縮 |
| 計算機・システム | データ表現、電気電子回路、論理回路、CPU、メモリ、OS、並行並列、分散、組み込み |
| ネットワーク | 階層、LAN、IP、経路、DNS、TCP/UDP、アプリ通信、無線、運用 |
| セキュリティ | リスク、暗号、公開鍵、TLS、認証、認可、Web、システム、防御運用、発展暗号 |
| データ・AI | データ設計、SQL、トランザクション、機械学習、ニューラルネット、探索推論、自然言語処理 |
| プログラミング・開発 | プログラム、オブジェクト指向、データ構造、算法、言語処理系、Git、設計テスト、Web実装 |
| メディア・HCI | 信号、画像、CG、ユーザビリティ、アクセシビリティ |
| 総合・倫理・研究 | 総合演習、倫理、実験と研究 |

## 画面

ホームは分野名・説明・件数を示すカードです。一覧には共通の分野選択、テーマの開閉式ナビ、説明付き単元カードを置きます。検索と分類を組み合わせ、検索に対応した件数も表示します。結果は24件ずつで、ページ・検索・分類はURLに含まれます。ブラウザの戻る操作と直リンクが使えますが、入力を学習記録として保存する処理はありません。

科目一覧は横並びの長い列を廃止し、検索可能な縦の開閉式一覧にしています。選んだ科目を開いた時だけ単元を配置します。`確率・統計` などの名称を中黒で分割せず、`src/curriculum-index.js` の明示的な対応表で個別の教材を関連づけています。関連づけは独自の案内であり、公式シラバスの確認結果とは異なります。

従来の `#/catalog?track=...`、`area=C01`、`topic=N07`、`#/course/...`、単元IDのURLも維持しています。新しい主分類ではCRCのように旧ネットワーク単元が数学側に属する場合がありますが、旧URLでは以前の対象単元を引き続き選べます。

## 保守と確認

追加単元は主分類を明示してください。未分類・重複・空テーマは検査で失敗します。`scripts/modules.mjs` が読み込み順の基準です。既存のJS/CSS編集はビルド不要。参照するファイルを追加した場合だけ `npm run build` で小さな `index.html` を更新します。公開元は main / (root) のままです。

- `tests/taxonomy.test.mjs`: 主分類、合計、科目名、検索、ページ欠落と旧URLの検査。
- `tests/library-browser.mjs`: Chromium/Firefox/WebKitでホーム、一覧、科目、キーボード、ゼロ件、61テーマ、314単元のページ送りを確認。320/390/768/1440/1920pxとPagesのサブパスで動作を測定します。
- `Library taxonomy and navigation`: 読み取り専用のCI。画面の寸法・操作結果を検査し、スクリーンショットと対応表を成果物に保存します。実機や学習者による評価とは区別します。
