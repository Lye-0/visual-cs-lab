## 時刻の判断例

- `A 0 3 0`: CPUを区間[0,1)、[1,2)、[2,3)で実行。完了は3です。
- `A 0 3/2/1 0`: 最初のCPUが3で完了し、I/Oは[3,5)。5で再開して6で終了します。
- 到着時刻が2のCPU3tickは5で終了します。複数仕事とI/Oを重ねた場合も、CPU時間・I/O時間・ready待ちの合計とターンアラウンドを照合します。
