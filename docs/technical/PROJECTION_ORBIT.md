# 立方体の投影図を操作する

`c18-projection` は立方体の頂点を透視投影した図を表示する。通常教材・詳細教材・自由実験の主図で、中ボタンドラッグの横方向はY軸回転、縦方向はX軸回転、ホイールは視点距離に対応する。右へドラッグするとY回転角は減り、左へドラッグすると増える。左右の矢印キーも同じ方向へ動く。中ボタンを離すとドラッグを終える。焦点を当てた図では上下の矢印キーでX軸回転、`+`・`-`で距離を変えられる。角度と距離は元の数値入力にも反映し、初期例へ戻せる。

既定のX軸角0°は従来の投影を保つ。角度はY軸−180〜180°、X軸−75〜75°、距離は3〜10で制限する。描画中の図と入力欄は前の結果を保持し、最新の計算ができてから入れ替える。

`gap-137` は画素中心・クリッピング・深度を同じ条件で比較する教材で、操作対象は固定された描画パイプラインである。`gap-138` は固定正面視点の法線と光の対応を読む教材である。これらと2D平面グラフには立体回転を加えない。

比較用に並べた図は条件A・Bを固定して読むため、操作対象から外す。

検証は `tests/projection-orbit.test.mjs` で既定投影・境界値を、`tests/projection-orbit-browser.mjs` で3種類の画面のドラッグ、ホイール、キーボード、リセット、2D図への非適用を確認する。
