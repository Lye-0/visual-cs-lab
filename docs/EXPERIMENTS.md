# 実験一覧

144本。収録数はモデル定義から生成しています。各分類の代表実験であり、関連規格の全機能を再現するものではありません。

## C01 情報の表現

0と1から、数・文字・情報へ

| ID | 単元名 | 学ぶこと | モデル |
|---|---|---|---|
| c01-bits | 2進数と符号付き整数 | ビットを切り替え、同じ0と1を符号なし整数と2の補数で読み比べます。 | 整数を実計算 |
| c01-float | 浮動小数点と丸め誤差 | 小数を32ビットで保存し、元の数と保存後の数の差を確かめます。 | IEEE 754 binary32 実変換 |
| c01-utf8 | 文字コードとUTF-8 | 文字・コードポイント・バイト列を並べ、文字ごとのデータ量を調べます。 | UTF-8の実エンコード |
| c01-huffman | ハフマン符号と圧縮 | 文字の出現頻度から符号を作り、圧縮する前後のビット数を比べます。 | Huffman符号を実計算 |
| c01-hamming | ハミング符号と誤り訂正 | 送信データの1ビットを反転し、検査から誤りの位置を求める手順を追います。 | Hamming(7,4)を実計算 |
