## 修正した点

| 問題 | 変更と理解への効果 |
|---|---|
| 計算記録の行列・図・式が、各行の折り畳みの中に隠れていた | `ledger` の各行へ実際の図・表を表示する。理由と対象を同時に読み、前後を比べられる。長い記録は6件ずつ追加する |
| 「この値に至る式・判断」を開いても、途中の見出しと説明しかなかった | `inspect` と `compare` の導出にも、元の計算フレームの図・表・値を残す。開くまで生成せず、6件ずつ追加して読み込み・DOM量を抑える |
| 計算記録や比較の表が選択可能に見えるのに反応しなかった | 選んだ記録の図だけを更新する。過去の記録を選んで最終状態に置き換えない。キーボードでも行・列の対応を確認できる |
| 続きを表示すると、それ以前の計算記録まで描き直していた | 新しい記録だけを追加する。前の図や選択を保持する。入力を編集した場合は古い結果を消し、実行後に新しい条件の記録を作る |
| GAP-002の拡大係数行列が「列1・列2・列3」で、右辺との区別が弱かった | 未知数 `x1, x2, …` と「右辺」を明示する。逆行列では左右のA・Iを区別する。解の章に、存在しない切替え操作を促す結果欄を出さない |
| GAP-006のヤコビ行列に、高さの関数の係数a,b,cと関数値が混ざっていた | 変換 `T(x,y)=(x²−y²,2xy)` の入力x,y、出力T₁,T₂、偏微分、面積倍率へ限定する。無関係な係数や高さの表を除き、係数変更に依存しないことを検査する |
| GAP-006で実際に扱う内容が異なる二組の章が同名だった | 「偏微分からヤコビ行列を組み立てる」「単位正方形の寄与を帯ごとに足す」と区別する。積分の最終結果へ無関係な一点の勾配を混ぜない |
| DBの4単元に「従来の計算記録」という開発経緯を表す章名が残っていた | 索引と走査、INNERとLEFT、挿入と分割、交互更新と逐次更新という、学ぶ対象を章名・問い・本文に書く |
| GAP-015・078に、現在の入力欄に合わない案内が残っていた | 観測値の個数nと標準誤差の関係、現在の未処理要求と保持済み割当の違いを説明する |
| URLのない提供資料まで空のリンクとして表示していた | 資料名と説明を本文として表示する。公開URLのある資料だけリンクにする |

変更は共通の表示と確認できた個別の不整合に絞った。単元固有の直接操作を一律の手順へ置き換えず、314単元のIDと588章のIDを保った。私的PDF・抽出画像を追加していない。
