# ノート整理・必要な単元だけを読み込む変更の検証

実施日：2026-09-26。基点は`01658be481cc5ffcc8ac7c00d1499fadaccaca61`。この記録は今回の未コミット作業ツリーに対するローカル検証であり、新しいGitHub Actionsの成功や公開を示すものではない。

## 変更したこと

- 13 PDF、209ページの構成を確認し、代表箇所を拡大して教材設計の原則を文書化した。PDF内の全式の検算や授業内容の完全な照合ではない。
- 私的PDFは元の保管場所に保持。Gitの無視対象を追加し、ローカルサーバーはPDF・私的資料・隠し開発情報の配信を拒否する。
- 現行設計と旧v2設計を分け、ドキュメント、ソース、検証の案内を追加した。既存の教材・ID・テスト・別ツールの作業用チェックアウトは削除していない。
- 初期の全モデル・全教材読み込みを、検索情報と選択単元の依存ファイルの読み込みに分割した。
- 共通の入力保持・取消しホストをセキュリティ教材の部品から分離した。
- WindowsのCRLFと生成時のLFだけで一覧検査が失敗する問題を修正した。内容の相違は引き続き検出する。

## 読み込み量

同じ既存内容を維持した状態の、非圧縮JS/CSSファイルサイズ合計。HTMLとfaviconは除外。遅延取得の選択単元データはJSとして含む。

| 画面 | JS/CSS合計 |
|---|---:|
| 変更前の初期取得（127 JS・25 CSS） | 2,788,641 bytes |
| 変更後のホーム（9 JS・5 CSS） | 646,608 bytes |
| 2進数を最初に開く場合・共通部を含む | 1,024,736 bytes |
| Git基本を最初に開く場合・共通部を含む | 990,576 bytes |
| 多変数微積分を最初に開く場合・共通部を含む | 1,055,641 bytes |
| Attentionを最初に開く場合・共通部を含む | 1,050,614 bytes |

初期取得は約76.8%削減。別の単元へ移る際にはロード済みの共通部を再実行しない。モデル・操作部品はファイル単位で共有しており、完全な関数単位の削除ではない。

これは転送元のファイルサイズの比較であり、本番回線のLCP・INP、圧縮後の転送量、実機の体感速度を測定した結果ではない。パフォーマンストレース用の専用MCPは利用できなかったため、ソースと実際のブラウザー要求で読み込み範囲を確認した。
