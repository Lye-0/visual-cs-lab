# Visual CS Lab — 2.0.0

**学びたい単元へ、まっすぐ。**

情報科学の20分野、ネットワーク20テーマ、セキュリティ24テーマを中心とする、144本のインタラクティブ実験です。ダークテーマを保ち、単元名・学ぶこと・操作方法・観察するポイントを明示しています。

この版では学習履歴、進捗、ノート、お気に入り、入力条件の永続保存を廃止しました。訪れたときに単元を探し、その場で実験するサイトです。

## 開き方

フォルダ内の **`index.html`** または配布用の **`Visual-CS-Lab-v2.html`** を通常のブラウザで開きます。CSSとJavaScriptをすべて含む単体HTMLで、外部ライブラリ・外部フォント・APIキー・ログインは不要です。

チャット内のプレビューや端末内の簡易ビューアがJavaScriptを制限しているときは、通常のブラウザで開いてください。暗号APIが利用できない場合は、付属のローカルサーバーを使います。

```powershell
# ZIPを展開し、visual-cs-lab フォルダで実行（Node.js 20以上）
npm start
```

表示される `http://127.0.0.1:4173` をブラウザで開きます。終了はターミナルで **Ctrl+C**。実行用の依存パッケージがないため、**`npm install` は不要**です。

ポートが使用中の場合：

```powershell
$env:PORT = "4174"
npm start
```

このサーバーは同じPCのループバックアドレスだけに待ち受けます。端末の設定変更や、実際のネットワーク機器の操作は行いません。

## 旧版から更新するとき

ZIPは**新しいフォルダに展開**する方法が確実です。既存の開発フォルダに組み込む場合、ソースの更新に加えて、旧版の **`tests/storage.test.mjs` を削除**してください。保存機能を廃止したため、このテストは `tests/privacy.test.mjs` に置き換えています。単体HTMLだけ使う場合は、v2のHTMLに置き換えるだけです。

## 単元を探す

トップに単元検索を置いています。入力するだけで検索結果が変わり、単元名と短い説明を確認して開けます。

検索対象は単元名、説明、問い、科目名、分野、用語などです。「TCP 再送」のような複数語、全角英数字、ひらがな・カタカナの揺れにも対応します。漢字の読みを自動推測する検索ではありません。

ネットワーク／セキュリティ／基礎・応用／総合演習の入口、20分野の一覧、科目名からの一覧、分野のつながり、8つのおすすめ順を用意しています。学習済みかどうかによる絞り込みや、単元を開くための前提条件はありません。

## 実験の使い方

どの単元でも、最初に**単元名・学ぶこと・実験の問い**を表示します。

| 操作 | できること |
|---|---|
| **A：初期条件を試す** | 最初の条件を確認し、手順のある実験は再生を開始します。 |
| **B：この条件で試す** | 単元ごとに用意した別の条件を実際に適用します。何を変えるかをボタンの近くに表示します。 |
| **ここを見る** | その実験で注目する値、関係、状態の違いを説明します。 |
| **入力・条件** | 自分で数値、スイッチ、選択肢、文字列を変更します。コードは編集後に「入力を反映」を押します。 |
| **AとBの結果を比べる** | 現在開いている単元の中だけで、条件と最終指標を比較します。「図と手順を並べて見る」でA/Bの図も比較できます。 |

### 手順を追う実験

「最初から再生」「一時停止」「1ステップ戻る／進む」「結果へ」を使用します。進行バーは押す・ドラッグする・矢印キー／Home／Endで操作でき、動かすと一時停止してその手順に移動します。最後まで進んだ後は「もう一度再生」で先頭から開始します。

再生速度は観察の間隔だけを変更し、計算モデル内の時間や最終結果には影響しません。条件変更時は古い再生を止め、新しい条件の**最初の状態**を表示します。検索や用語のダイアログを開いたとき、画面を移動したとき、ブラウザを非表示にしたときも停止します。

### 入力するとすぐ結果が変わる実験

論理ゲートなど、計算結果が1状態の単元には、意味のない再生ボタンや進行バーを表示しません。「この実験は入力に応じてその場で結果が変わります」と表示します。入力を変えるかA/Bの操作を使って、違いを確かめてください。

### 未反映の入力とエラー

コードの編集中・計算中は、以前の結果を新しい条件の結果として扱わないよう明示します。エラー時は古い図と指標を消し、修正方法を表示します。説明や「モデルと根拠」は引き続き確認できます。

### 3つの表示モード

「案内と一緒に」は上記の操作案内、「自由に試す」はデータと実行手順、「理解を確かめる」は単元ごとの3択問題を表示します。回答や正誤は保存せず、単元を離れると初期化します。修了認定や能力測定ではありません。

## 保存しないもの・一時的に残すもの

**保存しないもの：** 学習履歴、完了状態、理解度、閲覧回数、最終訪問単元、ノート、お気に入り、入力条件、比較条件、回答、表示設定。JSONインポート／エクスポートやノートのMarkdown出力もありません。

**現在の単元の中だけで使うもの：** 再生位置、計算結果、入力、A/B比較、選んだ回答。別画面へ移動するか再読み込みすると初期化します。「動きを抑える」はページを開いている間の一時的な設定です。

起動時に、旧版のローカル保存キー **`visual-cs-lab:v1`** の削除だけを試みます。旧データを読み込んで再利用することはありません。他のサイトやアプリの保存データは削除しません。

ブラウザに拒否された場合や、旧版と保存領域が異なる場合、そこにある旧データにはアクセスできません。異なるドメインやファイル位置のデータまで削除できるという意味ではありません。また、ブラウザ自身のURL閲覧履歴やファイルのダウンロード履歴は、このサイトの学習記録機能とは別です。

## モデルの位置づけ

表示はモデルの計算結果から生成します。数学の一般的な証明、実機の性能測定、安全性の認定とは区別してください。

AES-GCM、SHA-256、HMAC、ECDSA、PBKDF2はWeb Cryptoの実計算です。TLS、Webの脆弱性、無線、総合設計などには、範囲を絞った手順・条件モデルがあります。Gitは作業ファイル、ステージ、履歴、ブランチ等を扱う仮想リポジトリで、実際のGitやファイルには触れません。

詳しくは各単元の「モデルと根拠」と [docs/MODEL_SCOPE.md](docs/MODEL_SCOPE.md) を参照してください。

科目名との対応には、提供された「情報理工学部 学修要覧2026」pp.36–37 / 40–41を用いています。単元・問い・数値・学習順序は独自の設計であり、大学の公式教材、シラバス、試験範囲を定義するものではありません。元のPDFは再配布していません。

## 安全性

本体にアクセス解析、外部API、実機へのスキャン・攻撃・認証試行はありません。JavaScriptからの外向き通信はCSPの `connect-src 'none'` で禁止しています。参考資料へのリンクを自分で開く場合のみ外部サイトへ移動します。

**本物のパスワード、秘密鍵、機密情報を入力しないでください。** 保存しないサイトであっても、教材用の公開してよいデータで実験してください。

## キーボード・スマートフォン

`Ctrl+K / ⌘K` で検索、入力欄以外で `Space` は再生・一時停止、`← / →` は1ステップ、`Esc` はダイアログを閉じます。入力欄やボタンの標準操作を妨げないようにしています。

スマートフォンでは図と再生操作を条件入力より先に表示し、「条件を変える」で入力欄へ移動できます。大きい図は図の中をスクロールでき、ページ全体が横にはみ出さない構成です。

## 開発とテスト

```powershell
npm test              # 計算、境界値、プレイヤー、保存廃止、単元の案内、HTTPサーバー
npm run build         # src/ から単体 index.html を生成
npm run inventory     # 実験一覧と定義JSONを再生成
npm run check         # 上記をまとめて実行
```

ブラウザの任意テストは Python + Playwright + Chromium が必要です。これらはサイトの実行には不要です。

```powershell
python tests/browser_in_memory.py
python tests/browser_behaviors.py
```

`CHROMIUM_PATH` でブラウザの実行ファイル、`QA_OUTPUT` で結果の出力先を指定できます。初期状態では `test-results/` に出力します。テストは実URLへ接続せず、メモリ内の文書で実行します。

検証範囲と未検証部分は [docs/TEST_REPORT.md](docs/TEST_REPORT.md) に記載しています。変更履歴は [docs/CHANGELOG.md](docs/CHANGELOG.md) です。

## 公開とファイル構成

生成された `index.html` を静的ファイルとして配信できます。サブディレクトリでも使えるハッシュ形式の画面遷移です。公開先の設定やデプロイはこの配布物では行っていません。

```text
visual-cs-lab/
├─ index.html                   単体で開くサイト（生成物）
├─ src/                         計算モデル、教材定義、画面、スタイル
├─ scripts/build.mjs            単体HTMLの生成
├─ scripts/server.mjs           ローカル配信
├─ scripts/inventory.mjs        単元一覧の生成
├─ tests/                       自動テスト
├─ docs/                        設計、変更点、モデル範囲、検証、単元一覧
├─ .github/workflows/check.yml  Nodeによる検証
└─ README.md
```

`index.html` を直接変更せず、`src/` を編集して再生成してください。拡張方法は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) を参照してください。
