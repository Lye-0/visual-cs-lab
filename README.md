**小さな例を読み、図で確かめ、条件を変えて理解する。** 情報科学を学ぶための、ブラウザーで動く教材サイトです。数学・理論、プログラミング、計算機システム、ネットワーク、セキュリティ、データ・AI、メディアなどを扱います。

## ローカルで動かす

Node.js 20以上で `npm start` を実行し、`http://127.0.0.1:4173` を開いてください。起動時のビルドや `npm install` は不要です。

```text
npm run build       # index.htmlと単元別の配信データを更新
npm run inventory   # このREADMEの単元一覧とdata/experiments.jsonを更新
npm run check       # 生成物・Nodeテスト・単元一覧を検証
```

教材本文・モデル・操作部品は、必要な単元を選んだときに読み込みます。ブラウザーテストにはPlaywrightと対応ブラウザーが必要です。CIのバージョンは `.github/workflows/` を参照してください。
