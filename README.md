# Visual CS Lab — 3.0.0

**小さな例を読み、図で確かめ、条件を変えて理解する。**

情報科学の20分野を扱う、ダークテーマのインタラクティブ教材です。元の144単元を残し、情報理論・論理回路・仮想メモリ・通信の基礎15単元を追加しました。合計159単元です。ネットワーク20テーマ、セキュリティ24テーマを重点的に扱います。

学習履歴、進捗、完了状態、ノート、お気に入り、前回の入力は保存しません。訪れたときに、学びたい単元を探して始められます。

## 開く

通常のブラウザで `index.html` を開きます。CSS・JavaScriptを含む単体HTMLで、実行時の外部ライブラリ、外部フォント、APIキー、ログインは不要です。配布ZIP内の `Visual-CS-Lab.html` も同じサイトです。

開発フォルダから起動する場合は、Node.js 20以上で次を実行します。

```powershell
npm start
```

起動前に `src/` からHTMLを再生成し、`http://127.0.0.1:4173` で配信します。終了は `Ctrl+C`。**サイトを起動するための `npm install` は不要です。** ポートを変える場合は、実行前に `$env:PORT = "4174"` と指定します。

チャット内の簡易プレビューやファイル用ビューアではJavaScriptが制限される場合があります。通常のブラウザを使用してください。暗号APIが使えない場合は、ローカルHTTPサーバーで開きます。実際の端末のネットワーク設定は変更しません。

## 学びたい単元を探す

ホームの検索は、単元名、説明、問い、科目、分野、用語に対応します。「TCP 再送」のような複数語、全角英数、ひらがな・カタカナの表記揺れを扱います。漢字の読みを自動推定する機能ではありません。

ホームから「情報理論」「計算機科学入門」の説明順を参考にした単元一覧、ネットワーク、セキュリティ、20分野へ進めます。おすすめ順や前提単元も案内しますが、学習済み判定や閲覧制限はありません。

## 図と説明を一緒に読む

各単元では、正式な単元名・学ぶこと・問いを示し、次の区切りを自由に選べます。

| 区切り | 内容 |
|---|---|
| 背景と意味 | その仕組みが必要になる場面と、何をしているのかを説明します。 |
| 例を一緒に追う | 小さな初期例を読み、図・計算・判断の順に確かめます。 |
| 条件を変える | 何を変える比較なのかを示し、実際に入力を変更します。 |
| 理解を確かめる | 混同しやすい点を整理し、理由を選ぶ問題で確認します。 |

図の下の「今の段階」に、その状態の変化と理由を表示します。図・式・表を対応付けて選べる単元では、同じ対象を一緒に強調します。行列などの詳細を開いたまま、対応するビットを選んだり段階を進めたりできます。

初期例の説明は、その初期条件を対象にしています。自分で入力を変えた後は、現在の図と段階別の説明で結果を確認します。すべての規格や条件を説明する一般的な証明の代わりではありません。

### 操作

手順のある実験では、再生・一時停止・1つ戻る・次の判断や計算・最初・最後を使います。進行バーはクリック、ドラッグ、タッチ、矢印キー、Home、Endに対応し、操作すると一時停止します。最後で再生を押すと先頭から始まります。

再生速度は観察する間隔だけを変え、モデル内の計算時間や結果は変えません。1状態だけの直接操作の実験には、不要な再生や次段階のボタンを表示しません。

数値・スイッチ・選択肢・テキストの変更は再計算します。コードは「入力を反映」で明示的に反映します。複数の入力に誤りがある場合、それぞれを直すまで計算しません。古い図を新しい入力の結果として残さず、入力エラーや未反映を表示します。

比較は「4種類を同じ確率にする」など、条件の違いが分かる名前から始めます。比較元と現在の条件・最終結果を確認できます。比較によって勝手に再生は始まりません。

### 自由実験・詳細画面

単元上部のリンクから、既存の詳細ワークベンチも利用できます。Gitコマンド、仮想ネットワークの機器追加・接続・移動などはこの画面で扱います。新しい解説画面の図では、対象の説明や対応の確認を中心にしています。

画面切替で一時的な入力と比較は初期化されます。旧画面のA/B表示や3つのモードは詳細ワークベンチの機能であり、解説画面の4区切りとは別です。

## 保存しないもの

学習履歴、理解度、完了、閲覧回数、最終単元、ノート、お気に入り、条件、比較、回答、表示設定を永続保存しません。データのインポート／エクスポート機能もありません。

現在の単元の入力・再生位置・図の選択・開いた詳細・比較・回答だけをメモリ内に保持します。別の単元への移動や再読み込みで破棄します。「動きを抑える」は開いている間の一時的な設定です。

起動時には旧版の保存キー `visual-cs-lab:v1` の削除だけを試みます。旧データを読み込まず、他のアプリのキーを削除しません。別ドメインなど異なる保存領域の旧データや、ブラウザ自身の閲覧履歴まで削除できるわけではありません。保存APIが禁止されていても起動できます。

## モデルと参考資料

提供された授業ノート「情報理論」「計算機科学入門」は、用語・説明順・式と図の結び付けの参考です。対応する単元の参考欄にPDFページを示します。**ノートの全ページを再現したものではなく、PDFそのものや講義スライドの複製は公開していません。** 数値例、固定の回路・機械、図、プログラムは教材独自の実装で、異なる表記や省略を記載しています。

科目名の対応は提供された学修要覧を参考にしています。大学の公式教材、シラバスや試験範囲の保証ではありません。

数学の可視化を一般的な証明、条件モデルを実機の性能や安全性の認定と混同しないでください。AES-GCM、SHA-256、HMAC、ECDSA、PBKDF2はWeb Cryptoの実計算です。通信、TLS、Webの脆弱性、無線、総合演習などには、対象を絞った手順・条件モデルを使います。Gitは仮想リポジトリです。

各単元の「この教材の前提・省略・参考資料」と [モデルの範囲](docs/MODEL_SCOPE.md) を確認してください。

## 安全性と操作環境

アクセス解析、外部API、実機へのスキャンや認証試行はありません。CSPの `connect-src 'none'` で本体の外向き通信を禁止しています。参考リンクを自分で開く場合は外部サイトに移動します。本物のパスワード、秘密鍵、機密情報は入力せず、教材用データを使用してください。

`Ctrl+K / ⌘K` は検索、入力欄以外の `Space` は再生・停止、左右矢印は1段階、`Esc` はダイアログを閉じます。ボタンと入力欄は標準のキーボード操作を使用します。

スマートフォンでは説明・条件・図を縦に並べ、「図を見る」「入力条件へ戻る」「説明へ戻る」で往復できます。大きな図や表は内部スクロールを使い、画面全体を縮小して文字を読めなくすることを避けます。

## 開発と検証

```powershell
npm run check       # ビルド、Nodeの自動テスト、一覧の生成
npm run build       # src/ から index.html を再生成
npm run inventory   # 単元一覧とJSONを再生成
```

ブラウザ試験だけは、追加の開発用ツールが必要です。サイトの実行依存にはしません。

```powershell
npm install --no-save --package-lock=false --ignore-scripts playwright@1.63.0
npx playwright install chromium
npm run build
npm run test:browser
```

テストは実際のローカルHTTPサーバーを使います。全159単元のデスクトップ幅・モバイル幅、再生や入力の回帰試験、ブラウザ内の暗号計算を確認し、結果とスクリーンショットを `review-output/` へ出力します。スマートフォンの実機試験ではありません。

最新の成功したCIの記録は [v3検証記録](docs/verification/TEST_REPORT-v3.md) と [機械可読な結果](docs/verification/v3.json) に反映されます。生成前のソースコミットではこれらのファイルがまだない場合があります。**旧 `docs/TEST_REPORT.md`、旧スクリーンショット、旧 `browser-report.json` はv2の記録であり、v3の検証結果ではありません。** Pythonのメモリ内文書テストも旧版用です。

自動テストの通過は、初心者にとって十分分かりやすいことや、全内容の正しさの保証とは別です。検証していないブラウザ、実機、教材レビューの限界は検証記録に明記します。

## 生成物とGitHub Actions

`index.html` は直接編集せず `src/` を編集します。読み込み順は `scripts/modules.mjs` で一元管理しています。`npm start` は起動前に必ずビルドします。

`Lesson review` はテストに成功した場合だけHTML・ソースZIP・検証記録を成果物へまとめます。作業ブランチ `feat/notebook-led-learning` へのpush時だけ、生成物のSHA-256一致を確認してHTMLと一覧・記録を同じブランチに追記します。PRイベントやmainには書き込みません。ブランチが検証中に進んだ場合は上書きせず、force pushも行いません。

配布先はハッシュ形式の画面遷移を扱える静的ホスティングです。この改修ではmainへのマージとデプロイは行いません。
